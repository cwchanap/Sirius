# HPA-380 Main Menu and Deterministic Continue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Sirius's generic centred Main Menu with the approved scene-authored layout, deterministic Continue behavior, and one local `UIScreenHost` that owns Load, Settings, and Main Menu error presentation without redesigning those downstream screens.

**Architecture:** Keep `MainMenu` as the only root controller and keep `SaveManager`/`SettingsManager` as existing domain owners. Add one pure `SaveSlotInfo` selector, scene-author the lower-left Main Menu composition, host existing Load/Settings views through the merged `UIScreenHost`, use one local themed `AcceptDialog` path until HPA-572, and mirror `Game`'s narrow host-teardown gate before scene replacement. Do not register the Main Menu surface itself as a host entry; explicitly disable its five root actions while a hosted child is active.

**Tech Stack:** Godot 4.6.2, C#/.NET 8, GdUnit4, existing Sirius Theme/components, `SiriusUiMetrics`, `SiriusInputHint`, `UIScreenHost`, `SaveManager`, `SaveLoadDialog`, and `SettingsMenuController`.

## Global Constraints

- Primary target is desktop landscape with mouse, keyboard, and gamepad.
- Minimum supported logical resolution is 640×360.
- Compact reflow is `SiriusUiMetrics.IsCompact(viewportSize)`; do not introduce another breakpoint.
- Standard/compact safe margins come from `SiriusUiMetrics.SafeMargin`.
- Maximum centred content width is `SiriusUiMetrics.MaximumContentWidth` (1600 logical pixels).
- Minimum action targets come from `SiriusUiMetrics.MinimumTarget` (44px standard, 40px compact).
- Continue eligibility is exactly `Exists && !IsCorrupted` across manual slots 0–2 and autosave slot 3.
- Continue orders stored `Timestamp` descending; `DateTime.MinValue` is older than usable timestamps; equal timestamps rank autosave 3, then manual 0, 1, 2.
- Compare/format stored timestamps without timezone normalization or save migration.
- Full Continue activation must use the existing `SaveManager.LoadGame` / `LoadAutosave` path.
- A failed full Continue load must never fall back to New Game; open Load and show a themed error instead.
- Preserve current New Game, Load, Settings, Quit, save validation, and Game-scene handoff behavior.
- Main Menu root Cancel is a no-op.
- Reuse the existing HPA-383 Settings scene/controller without modifying it.
- Reuse the existing `SaveLoadDialog` until HPA-384; do not redesign save/load slots here.
- HPA-572 owns shared confirmation/warning/error components; HPA-380 may use only a private local themed `AcceptDialog` helper for its concrete save/load messages.
- Do not add a Main Menu view model, navigation service, scene router, save facade, generic message framework, transition framework, or compatibility layer.
- Do not modify `SaveManager`, `SaveLoadDialog`, `SettingsMenuController`, `UIScreenHost`, Sirius Theme resources, or `project.godot` unless implementation demonstrates the design is impossible; reassess scope before doing so.

```csharp
internal static SaveSlotInfo? SelectContinueSave(
    IReadOnlyList<SaveSlotInfo> slots)
{
    SaveSlotInfo? best = null;
    foreach (var candidate in slots)
    {
        if (!candidate.Exists || candidate.IsCorrupted)
            continue;

        if (best == null || IsBetterContinueCandidate(candidate, best))
            best = candidate;
    }

    return best;
}

private static bool IsBetterContinueCandidate(
    SaveSlotInfo candidate,
    SaveSlotInfo current)
{
    var timestampComparison = candidate.Timestamp.CompareTo(current.Timestamp);
    if (timestampComparison != 0)
        return timestampComparison > 0;

    return ContinueTieRank(candidate.SlotIndex) <
           ContinueTieRank(current.SlotIndex);
}

private static int ContinueTieRank(int slot) => slot switch
{
    3 => 0,
    0 => 1,
    1 => 2,
    2 => 3,
    _ => int.MaxValue
};
```

Do not sort/clone the input and do not call `ToLocalTime`, `ToUniversalTime`, or any migration helper.

private void RefreshContinueState()
{
    var saveManager = SaveManager.Instance;
    if (saveManager == null || !IsInstanceValid(saveManager))
    {
        _continueSave = null;
        RefreshContinuePresentation();
        return;
    }

    var slots = new SaveSlotInfo[4];
    for (var slot = 0; slot < slots.Length; slot++)
        slots[slot] = saveManager.GetSaveSlotInfo(slot);

    _continueSave = SelectContinueSave(slots);
    RefreshContinuePresentation();
}

private void RefreshContinuePresentation()
{
    var info = _continueSave;
    _continueSummary.Visible = info != null;

    if (info == null)

        _continueSlotLabel.Text = string.Empty;
        _continueDetailLabel.Text = string.Empty;
        _continueTimestampLabel.Text = string.Empty;
        RefreshActionAvailability();
        return;

    _continueSlotLabel.Text = info.GetDisplayName();
    _continueDetailLabel.Text =
        $"{info.PlayerName}  ·  Lv {info.PlayerLevel}  ·  {info.GetFloorName()}";
    _continueTimestampLabel.Text = info.Timestamp == DateTime.MinValue
        ? string.Empty
        : info.Timestamp.ToString("yyyy-MM-dd HH:mm");

    RefreshActionAvailability();

private void RefreshLayout()
{
    var viewportSize = GetViewportRect().Size;
    var compact = SiriusUiMetrics.IsCompact(viewportSize);
    var margin = SiriusUiMetrics.SafeMargin(compact);
    var usableWidth = Mathf.Max(0f, viewportSize.X - (margin * 2f));
    var contentWidth = Mathf.Min(usableWidth, SiriusUiMetrics.MaximumContentWidth);
    var side = (viewportSize.X - contentWidth) / 2f;

    _safeFrame.SetAnchorsAndOffsetsPreset(Control.LayoutPreset.FullRect);
    _safeFrame.OffsetLeft = side;
    _safeFrame.OffsetRight = -side;
    _safeFrame.OffsetTop = margin;
    _safeFrame.OffsetBottom = -margin;

    var targetHeight = SiriusUiMetrics.MinimumTarget(compact).Y;
    foreach (var button in _rootActions)
        button.CustomMinimumSize = new Vector2(button.CustomMinimumSize.X, targetHeight);

    _menuRail.AddThemeConstantOverride("separation", compact ? 4 : 8);
    _menuRail.CustomMinimumSize = new Vector2(compact ? 280 : 360, 0);

    _wordmarkLabel.ThemeTypeVariation = compact
        ? SiriusThemeTypes.DisplayCompact
        : SiriusThemeTypes.Display;
    _continueSlotLabel.ThemeTypeVariation = compact
        ? SiriusThemeTypes.SectionCompact
        : SiriusThemeTypes.Section;
    _continueDetailLabel.ThemeTypeVariation = compact
        ? SiriusThemeTypes.BodyCompact

private static object? InvokePrivateAcrossHierarchyWithResult(
    object instance,
    string methodName,
    params object?[] arguments)
{
    for (var type = instance.GetType(); type != null; type = type.BaseType)
    {
        var method = type.GetMethod(
            methodName,
            BindingFlags.NonPublic | BindingFlags.Instance | BindingFlags.DeclaredOnly);
        if (method != null)
            return method.Invoke(instance, arguments);
    }

    throw new MissingMethodException(instance.GetType().Name, methodName);
}
