# HPA-380 Main Menu and Deterministic Continue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Sirius's generic centred Main Menu with the approved scene-authored layout, deterministic Continue behavior, and one local `UIScreenHost` that owns Load, Settings, and Main Menu error presentation without redesigning those downstream screens.

**Architecture:** Keep `MainMenu` as the only root controller and keep `SaveManager`/`SettingsManager` as existing domain owners. Add one pure `SaveSlotInfo` selector, scene-author the lower-left Main Menu composition, host existing Load/Settings views through the merged `UIScreenHost`, use one private themed `AcceptDialog` path until HPA-572, and mirror `Game`'s narrow `PrepareForTeardown()` gate before scene replacement. Do not register the Main Menu itself as a host entry; use one shared root-action predicate so disabled controls and handler guards agree.

**Tech Stack:** Godot 4.6.2, C#/.NET 8, GdUnit4, existing Sirius Theme/components, `SiriusUiMetrics`, `SiriusInputHint`, `UIScreenHost`, `SaveManager`, `SaveLoadDialog`, and `SettingsMenuController`.

## Global Constraints

- Primary target is desktop landscape with mouse, keyboard, and gamepad.
- Minimum supported logical resolution is 640×360.
- Compact reflow is `SiriusUiMetrics.IsCompact(viewportSize)`; do not introduce another breakpoint.
- Safe margins come from `SiriusUiMetrics.SafeMargin`; maximum centred content width is `SiriusUiMetrics.MaximumContentWidth` (1600).
- Minimum action targets come from `SiriusUiMetrics.MinimumTarget` (44px standard, 40px compact).
- Continue eligibility is exactly `Exists && !IsCorrupted` across manual slots 0–2 and autosave slot 3.
- Continue orders stored `Timestamp` descending; `DateTime.MinValue` is oldest; equal timestamps rank autosave 3 then manual 0, 1, 2.
- The no-timezone-normalization rule applies to the new Continue selector/summary only. Preserve legacy `SaveLoadDialog` timestamp presentation unchanged until HPA-384.
- Full Continue activation uses existing `SaveManager.LoadGame` / `LoadAutosave` behavior.
- Failed Continue never starts New Game; it opens Load plus a themed error when possible.
- Preserve current New Game, Load, Settings, Quit, validation, and Game-scene handoff behavior.
- Root Cancel is a consumed no-op.
- Reuse HPA-383 Settings unchanged.
- Reuse existing `SaveLoadDialog` until HPA-384.
- HPA-572 owns shared confirmations/warnings/errors; HPA-380 may use only a private local themed `AcceptDialog` helper.
- Do not add a Main Menu view model, navigation service, scene router, save facade, generic message framework, transition framework, or compatibility layer.
- Do not modify `SaveManager`, `SaveLoadDialog`, `SettingsMenuController`, `UIScreenHost`, Sirius Theme resources, or `project.godot` unless implementation proves this design impossible; stop and reassess scope first.

Add to `MainMenu.cs`:

```csharp
internal static SaveSlotInfo? SelectContinueSave(
    IReadOnlyList<SaveSlotInfo> slots)
{
    SaveSlotInfo? best = null;
    foreach (var candidate in slots)
    {
        if (!candidate.Exists || candidate.IsCorrupted)
            continue;

        if (best == null || IsBetterContinueCandidate(candidate, best))
            best = candidate;
    }

    return best;
}

private static bool IsBetterContinueCandidate(
    SaveSlotInfo candidate,
    SaveSlotInfo current)
{
    var timestampComparison = candidate.Timestamp.CompareTo(current.Timestamp);
    if (timestampComparison != 0)
        return timestampComparison > 0;

    return ContinueTieRank(candidate.SlotIndex) < ContinueTieRank(current.SlotIndex);
}

private static int ContinueTieRank(int slot) => slot switch
{
    3 => 0,
    0 => 1,
    1 => 2,
    2 => 3,
    _ => int.MaxValue
};
```

Do not sort/clone input and do not call `ToLocalTime`/`ToUniversalTime`.

private void RefreshContinueState()
{
    var saveManager = SaveManager.Instance;
    if (saveManager == null || !IsInstanceValid(saveManager))
    {
        _continueSave = null;
        RefreshContinuePresentation();
        return;
    }

    var slots = new SaveSlotInfo[4];
    for (var slot = 0; slot < slots.Length; slot++)
        slots[slot] = saveManager.GetSaveSlotInfo(slot);

    _continueSave = SelectContinueSave(slots);
    RefreshContinuePresentation();
}

private void RefreshContinuePresentation()
{
    var info = _continueSave;
    _continueSummary.Visible = info != null;

    if (info == null)
    {
        _continueSlotLabel.Text = string.Empty;
        _continueDetailLabel.Text = string.Empty;
        _continueTimestampLabel.Text = string.Empty;
        RefreshActionAvailability();
        return;
    }

    _continueSlotLabel.Text = info.GetDisplayName();
    _continueDetailLabel.Text =
        $"{info.PlayerName}  ·  Lv {info.PlayerLevel}  ·  {info.GetFloorName()}";
    _continueTimestampLabel.Text = info.Timestamp == DateTime.MinValue
        ? string.Empty
        : info.Timestamp.ToString("yyyy-MM-dd HH:mm");

    RefreshActionAvailability();
}

            return UIInputInterception.DeferToPolicy;

            else dialog.Hide();

        return false;

- [ ] **Step 9: Mirror Game's teardown gate**

```csharp
private const string GameScenePath = "res://scenes/game/Game.tscn";
private string? _pendingScenePath;
private bool _sceneChangeCommitted;

private void RequestSceneChange(string path)
{
    if (_sceneChangeCommitted)
        return;

    _sceneChangeCommitted = true;
    _pendingScenePath = path;
    RefreshActionAvailability();
    ContinueSceneChangeAfterUiTeardown();
}

private void ContinueSceneChangeAfterUiTeardown()
{
    if (!GodotObject.IsInstanceValid(this) || !IsInsideTree())
        return;

    if (_screenHost != null && IsInstanceValid(_screenHost) &&
        _screenHost.PrepareForTeardown() == UIScreenTeardownPreparationStatus.Deferred)
    {
        Callable.From(ContinueSceneChangeAfterUiTeardown).CallDeferred();
        return;
    }

    var path = _pendingScenePath;
    _pendingScenePath = null;
    if (!string.IsNullOrEmpty(path))
        ChangeSceneToFile(path);
}
```

Do not reset `_sceneChangeCommitted`; it is a one-way gate.
