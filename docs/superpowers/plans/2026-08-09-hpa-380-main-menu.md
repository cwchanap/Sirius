# HPA-380 Main Menu and Deterministic Continue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Sirius's generic centred Main Menu with the approved scene-authored layout, deterministic Continue behavior, and one local `UIScreenHost` that owns Load, Settings, and Main Menu error presentation without redesigning those downstream screens.

**Architecture:** Keep `MainMenu` as the only root controller and keep `SaveManager`/`SettingsManager` as existing domain owners. Add one pure `SaveSlotInfo` selector, scene-author the lower-left Main Menu composition, host existing Load/Settings views through the merged `UIScreenHost`, use one private themed `AcceptDialog` path until HPA-572, and mirror `Game`'s narrow `PrepareForTeardown()` gate before scene replacement. Do not register the Main Menu itself as a host entry; use one shared root-action predicate so disabled controls and handler guards agree.

**Tech Stack:** Godot 4.6.2, C#/.NET 8, GdUnit4, existing Sirius Theme/components, `SiriusUiMetrics`, `SiriusInputHint`, `UIScreenHost`, `SaveManager`, `SaveLoadDialog`, and `SettingsMenuController`.

## Global Constraints

- Primary target is desktop landscape with mouse, keyboard, and gamepad.
- Minimum supported logical resolution is 640×360.
- Compact reflow is `SiriusUiMetrics.IsCompact(viewportSize)`; do not introduce another breakpoint.
- Safe margins come from `SiriusUiMetrics.SafeMargin`; maximum centred content width is `SiriusUiMetrics.MaximumContentWidth` (1600).
- Minimum action targets come from `SiriusUiMetrics.MinimumTarget` (44px standard, 40px compact).
- Continue eligibility is exactly `Exists && !IsCorrupted` across manual slots 0–2 and autosave slot 3.
- Continue orders stored `Timestamp` descending; `DateTime.MinValue` is oldest; equal timestamps rank autosave 3 then manual 0, 1, 2.
- The no-timezone-normalization rule applies to the new Continue selector/summary only. Preserve legacy `SaveLoadDialog` timestamp presentation unchanged until HPA-384.
- Full Continue activation uses existing `SaveManager.LoadGame` / `LoadAutosave` behavior.
- Failed Continue never starts New Game; it opens Load plus a themed error when possible.
- Preserve current New Game, Load, Settings, Quit, validation, and Game-scene handoff behavior.
- Root Cancel is a consumed no-op.
- Reuse HPA-383 Settings unchanged.
- Reuse existing `SaveLoadDialog` until HPA-384.
- HPA-572 owns shared confirmations/warnings/errors; HPA-380 may use only a private local themed `AcceptDialog` helper.
- The five root Buttons—Continue, New Game, Load, Settings, Quit—are the complete actionable root-control set for this ticket.
- Do not add a Main Menu view model, navigation service, scene router, save facade, generic message framework, transition framework, or compatibility layer.
- Do not modify `SaveManager`, `SaveLoadDialog`, `SettingsMenuController`, `UIScreenHost`, Sirius Theme resources, or `project.godot` unless implementation proves this design impossible; stop and reassess scope first.

- [ ] **Step 3: Add the minimal pure selector**

Add `using System;` and `using System.Collections.Generic;`, then:

```csharp
internal static SaveSlotInfo? SelectContinueSave(
    IReadOnlyList<SaveSlotInfo> slots)
{
    SaveSlotInfo? best = null;
    foreach (var candidate in slots)
    {
        if (!candidate.Exists || candidate.IsCorrupted)
            continue;

        if (best == null || IsBetterContinueCandidate(candidate, best))
            best = candidate;
    }

    return best;
}

private static bool IsBetterContinueCandidate(
    SaveSlotInfo candidate,
    SaveSlotInfo current)
{
    var timestampComparison = candidate.Timestamp.CompareTo(current.Timestamp);
    if (timestampComparison != 0)
        return timestampComparison > 0;

    return ContinueTieRank(candidate.SlotIndex) < ContinueTieRank(current.SlotIndex);
}

private static int ContinueTieRank(int slot) => slot switch
{
    3 => 0,
    0 => 1,
    1 => 2,
    2 => 3,
    _ => int.MaxValue
};
```

Do not sort/clone input and do not call `ToLocalTime`/`ToUniversalTime`.

```csharp
private void RefreshContinueState()
{
    var saveManager = SaveManager.Instance;
    if (saveManager == null || !IsInstanceValid(saveManager))
    {
        _continueSave = null;
        RefreshContinuePresentation();
        return;
    }

    var slots = new SaveSlotInfo[4];
    for (var slot = 0; slot < slots.Length; slot++)
        slots[slot] = saveManager.GetSaveSlotInfo(slot);

    _continueSave = SelectContinueSave(slots);
    RefreshContinuePresentation();
}

private void RefreshContinuePresentation()
{
    _continueSummary.Visible = _continueSave != null;
    RefreshLayout();
    RefreshActionAvailability();
}

private void ApplyContinueText(bool compact)
{
    var info = _continueSave;
    if (info == null)
    {
        _continueSlotLabel.Text = string.Empty;
        _continueDetailLabel.Text = string.Empty;
        _continueTimestampLabel.Text = string.Empty;
        return;
    }

    var slot = info.GetDisplayName();
    var floor = info.GetFloorName();

    _continueSlotLabel.Visible = !compact;
    _continueSlotLabel.Text = slot;
    _continueDetailLabel.Text = compact
        ? $"{slot} · {info.PlayerName} · Lv {info.PlayerLevel} · {floor}"
        : $"{info.PlayerName} · Lv {info.PlayerLevel} · {floor}";
```

```csharp
private void OnResized() => RefreshLayout();

private void RefreshLayout()
{
    if (_safeFrame == null || _menuRail == null)
        return;

    var viewportSize = GetViewportRect().Size;
    var compact = SiriusUiMetrics.IsCompact(viewportSize);
    var margin = SiriusUiMetrics.SafeMargin(compact);
    var usableWidth = Mathf.Max(0f, viewportSize.X - (margin * 2f));
    var contentWidth = Mathf.Min(usableWidth, SiriusUiMetrics.MaximumContentWidth);
    var side = (viewportSize.X - contentWidth) / 2f;

    _safeFrame.OffsetLeft = side;
    _safeFrame.OffsetRight = -side;
    _safeFrame.OffsetTop = margin;
    _safeFrame.OffsetBottom = -margin;

    var targetHeight = SiriusUiMetrics.MinimumTarget(compact).Y;
    foreach (var button in _rootActions)
        button.CustomMinimumSize = new Vector2(button.CustomMinimumSize.X, targetHeight);

    _menuRail.AddThemeConstantOverride("separation", compact ? 4 : 8);
    _menuRail.CustomMinimumSize = new Vector2(compact ? 280 : 360, 0);

    _wordmarkLabel.ThemeTypeVariation = compact
        ? SiriusThemeTypes.DisplayCompact
        : SiriusThemeTypes.Display;
    _continueSlotLabel.ThemeTypeVariation = compact
        ? SiriusThemeTypes.SectionCompact
        : SiriusThemeTypes.Section;
    _continueDetailLabel.ThemeTypeVariation = compact
        ? SiriusThemeTypes.BodyCompact
        : SiriusThemeTypes.Body;
    _continueTimestampLabel.ThemeTypeVariation = compact
        ? SiriusThemeTypes.MetadataCompact
        : SiriusThemeTypes.Metadata;

    ApplyContinueText(compact);
    _continueTimestampLabel.Visible =
        !compact &&
        _continueSave != null &&
        _continueSave.Timestamp != DateTime.MinValue;
    _selectHint.Compact = compact;
}
```

```csharp
private bool TryOpenMessage(
    string title,
    string message,
    Control? restoreFocus,
    UIScreenHandle? parent = null,
    bool closeParentOnDismiss = false)
{
    if (_screenHost == null || !IsInstanceValid(_screenHost) ||
        _screenHost.IsKindActive(UIScreenKinds.SaveError))
        return false;

    var popup = new AcceptDialog
    {
        Title = title,
        DialogText = message,
        Exclusive = true,
        Theme = GD.Load<Theme>(SiriusThemeTypes.ResourcePath)
    };

    var handled = false;
    Action close = () =>
    {
        if (handled)
            return;
        handled = true;
        TryCloseHostedMessage(UIScreenCloseReason.ExplicitAction);
    };

    popup.Confirmed += close;
    popup.Canceled += close;
    popup.CloseRequested += close;

    var result = _screenHost.TryPresent(popup, new UIScreenEntrySpec
    {
        Kind = UIScreenKinds.SaveError,
        Layer = UIScreenLayer.Modal,
        InputPriority = UIInputPriority.Blocking,
        ProcessPolicy = UIProcessPolicy.Always,
        Parent = parent,
        ExclusiveGroup = UIScreenExclusiveGroups.BlockingPrompt,
        PauseTree = false,
        BlockGameplayInput = false,
        Cursor = UICursorPolicy.Visible,
        Hud = UIHudPolicy.Inherit,
        LowerLayers = UILowerLayerPolicy.VisibleInert,
        Cancel = UICancelPolicy.Close,
        InitialFocus = () => popup.GetOkButton(),
        RestoreFocus = parent.HasValue || restoreFocus == null
            ? null
            : () => restoreFocus,
        SetPresented = visible =>
        {
            if (visible) popup.PopupCentered();
            else popup.Hide();
        },
        Cleanup = _ =>
        {
            if (IsInstanceValid(popup))
            {
                popup.Confirmed -= close;
                popup.Canceled -= close;
                popup.CloseRequested -= close;
            }

            if (ReferenceEquals(_messageDialog, popup))
            {
                _messageHandle = null;
                _messageDialog = null;
            }

            if (closeParentOnDismiss && parent.HasValue &&
                _screenHost != null && _screenHost.IsActive(parent.Value))
            {
                // UIScreenHost queues this close because cleanup executes while
                // the child close transaction is already draining.
                _screenHost.TryClose(parent.Value, UIScreenCloseReason.Programmatic);
            }

            RefreshActionAvailability();
        },
        NodeLifetime = UINodeLifetime.QueueFree
    });

    if (result.Status != UIScreenOpenStatus.Opened || !result.Handle.HasValue)
    {
        popup.Confirmed -= close;
        popup.Canceled -= close;
        popup.CloseRequested -= close;
        popup.QueueFree();
        return false;

    _messageDialog = popup;
    popup.PopupCentered();
    RefreshActionAvailability();
    return true;
}
```
