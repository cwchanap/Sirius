# HPA-380 Main Menu and Deterministic Continue Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Sirius's generic centred Main Menu with the approved scene-authored layout, deterministic Continue behavior, and one local `UIScreenHost` that owns Load, Settings, and Main Menu error presentation without redesigning those downstream screens.

**Architecture:** Keep `MainMenu` as the only root controller and keep `SaveManager`/`SettingsManager` as existing domain owners. Add one pure `SaveSlotInfo` selector, scene-author the lower-left Main Menu composition, host existing Load/Settings views through the merged `UIScreenHost`, use one private hosted themed `AcceptDialog` path until HPA-572, and mirror `Game`'s narrow `PrepareForTeardown()` gate before scene replacement. Extract the already-proven safe-frame inset calculation into `SiriusUiMetrics` because HPA-380 is its second production consumer; migrate the exploration HUD to that helper without changing HUD behavior.

**Tech Stack:** Godot 4.6.2, C#/.NET 8, GdUnit4, existing Sirius Theme/components, `SiriusUiMetrics`, `SiriusInputHint`, `UIScreenHost`, `SaveManager`, `SaveLoadDialog`, and `SettingsMenuController`.

## Global Constraints

- Primary target is desktop landscape with mouse, keyboard, and gamepad.
- Minimum supported logical resolution is 640×360.
- Compact reflow remains `SiriusUiMetrics.IsCompact`; do not introduce another breakpoint.
- Maximum centred content width remains 1600 logical pixels.
- Minimum action targets remain 44px standard / 40px compact.
- Continue eligibility is exactly `Exists && !IsCorrupted` across manual slots 0–2 and autosave slot 3.
- Continue ordering compares stored `Timestamp` values descending; `DateTime.MinValue` is oldest; equal timestamps rank autosave 3, then manual 0, 1, 2.
- Continue **display** converts a non-MinValue timestamp with `.ToLocalTime()` to remain consistent with `SaveLoadDialog`; ordering/storage never convert or mutate timestamps.
- Full Continue activation uses existing `SaveManager.LoadGame` / `LoadAutosave` behavior.
- Failed Continue never starts New Game; it opens Load plus a themed error when possible.
- Preserve current New Game, Load, Settings, Quit, validation, and Game-scene handoff behavior.
- Root Cancel is a consumed no-op.
- Reuse HPA-383 Settings unchanged.
- Reuse existing `SaveLoadDialog` until HPA-384.
- HPA-572 owns shared confirmations/warnings/errors; HPA-380 may use only one private hosted `AcceptDialog` helper.
- The five root Buttons—Continue, New Game, Load, Settings, Quit—are the complete actionable root-control set.
- Do not add a Main Menu view model, navigation service, scene router, save facade, generic message framework, generic SaveLoad host factory, transition framework, or compatibility layer.
- Do not modify `SaveManager`, `SaveLoadDialog`, `SettingsMenuController`, `UIScreenHost`, Theme resources, or `project.godot` unless implementation proves this plan impossible; stop and reassess scope first.

- [ ] **Step 3: Add the minimal selector**

Add `using System;` and `using System.Collections.Generic;`, then:

```csharp
internal static SaveSlotInfo? SelectContinueSave(
    IReadOnlyList<SaveSlotInfo> slots)
{
    SaveSlotInfo? best = null;
    foreach (var candidate in slots)
    {
        if (!candidate.Exists || candidate.IsCorrupted)
            continue;

        if (best == null || IsBetterContinueCandidate(candidate, best))
            best = candidate;
    }

    return best;
}

private static bool IsBetterContinueCandidate(
    SaveSlotInfo candidate,
    SaveSlotInfo current)
{
    var timestampComparison = candidate.Timestamp.CompareTo(current.Timestamp);
    if (timestampComparison != 0)
        return timestampComparison > 0;

    return ContinueTieRank(candidate.SlotIndex) < ContinueTieRank(current.SlotIndex);
}

private static int ContinueTieRank(int slot) => slot switch
{
    3 => 0,
    0 => 1,
    1 => 2,
    2 => 3,
    _ => int.MaxValue
};
```

Do not sort/clone the input and do not call `ToLocalTime`/`ToUniversalTime` in this selector.

public static (bool Compact, float Margin, float SideInset)
    SafeFrameInsets(Vector2 viewportSize)
{
    var compact = IsCompact(viewportSize);
    var margin = SafeMargin(compact);
    var availableWidth = MathF.Max(0f, viewportSize.X - margin * 2f);
    var contentWidth = MathF.Min(availableWidth, MaximumContentWidth);
    var sideInset = MathF.Max(
        margin,
        (viewportSize.X - contentWidth) / 2f);
    return (compact, margin, sideInset);
}

private void RefreshContinueState()
{
    var manager = SaveManager.Instance;
    if (manager == null || !IsInstanceValid(manager))
    {
        _continueSave = null;
        RefreshContinuePresentation();
        return;
    }

    var slots = new SaveSlotInfo[4];
    for (var slot = 0; slot < slots.Length; slot++)
        slots[slot] = manager.GetSaveSlotInfo(slot);

    _continueSave = SelectContinueSave(slots);
    RefreshContinuePresentation();
}

private void RefreshContinuePresentation()
{
    if (_continueSummary == null)
        return;

    _continueSummary.Visible = _continueSave != null;
    RefreshLayout();
    RefreshActionAvailability();
}

private void ApplyContinueText(bool compact)
{
    var info = _continueSave;
    if (info == null)
    {
        _continueSlotLabel.Text = string.Empty;
        _continueDetailLabel.Text = string.Empty;
        _continueTimestampLabel.Text = string.Empty;
        return;
    }

    var slot = info.GetDisplayName();
    var floor = info.GetFloorName();
    _continueSlotLabel.Visible = !compact;
    _continueSlotLabel.Text = slot;
    _continueDetailLabel.Text = compact
        ? $"{slot} · {info.PlayerName} · Lv {info.PlayerLevel} · {floor}"
        : $"{info.PlayerName} · Lv {info.PlayerLevel} · {floor}";
    _continueTimestampLabel.Text = info.Timestamp == DateTime.MinValue
        ? string.Empty
        : info.Timestamp.ToLocalTime().ToString("yyyy-MM-dd HH:mm");
}

private bool TryOpenMessage(
    string title,
    string message,
    Control? restoreFocus,
