# HPA-384 Save/Load Responsive Cards Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the runtime-built `SaveLoadDialog` with scene-authored responsive Save/Load cards and a hosted overwrite confirmation while preserving existing save-domain and scene-flow behavior.

**Architecture:** First prove whether the existing `SiriusModalShell` needs a height fix with a 640×360 runtime regression using only supported Godot 4.6 APIs. If the regression exposes the expected overflow defect, complete the shell's height/scroll contract there; if current shell behavior already satisfies the contract, keep the shell unchanged. Then add one `SaveSlotState`, one script-less card scene, one Save/Load screen/controller, and one small feature-specific overwrite confirmation scene/controller. Main Menu and Game keep their current local `UIScreenHost`s and domain handlers; overwrite becomes a real host child using the existing `UIScreenKinds.ConfirmOverwrite`.

**Tech Stack:** Godot 4.6.2, C#/.NET 8, GdUnit4, existing Sirius Theme / `SiriusModalShell` / `UIScreenHost`.

**Design:** `docs/superpowers/specs/2026-08-11-hpa-384-save-load-design.md`

## Global Constraints

- Preserve manual slots 0–2 and autosave slot 3.
- Preserve `SaveManager` ownership of file I/O, version checks, full loads, atomic writes, and backup restoration.
- Preserve `Game` ownership of gameplay save eligibility and `CollectSaveData`.
- Preserve Main Menu/Game ownership of `PendingLoadData` and scene transitions.
- Preserve `SaveSlotInfo.Exists` / `IsCorrupted` semantics used by HPA-380 Continue.
- Do not expose Delete, playtime, thumbnails, renaming, cloud saves, auto-repair, extra slots, or fabricated metadata.
- Do not add a save facade, save view model, navigation service, host factory, card controller, collection renderer, or HPA-572 generic confirmation framework.
- Reuse `SiriusModalShell`, `SiriusUiMetrics`, existing local `UIScreenHost`s, and existing `UIScreenKinds.ConfirmOverwrite`.
- Save/Load and overwrite confirmation must be scene-authored `Control`s; no native Save/Load `AcceptDialog` remains.
- Settings keeps its existing page-local scroll ownership; any shared-shell change must respect a disabled shell `BodyScroll`.

```csharp
private void RefreshBodyHeight(Vector2 availableSize)
{
    if (_bodyScroll.VerticalScrollMode == ScrollContainer.ScrollMode.Disabled)
        return;

    var safeMargin = SiriusUiMetrics.SafeMargin(Compact);
    var maximumPanelHeight = Mathf.Max(0f, availableSize.Y - safeMargin * 2f);

    var currentBodyMinimum = _bodyScroll.GetCombinedMinimumSize().Y;
    var currentPanelMinimum = _panel.GetCombinedMinimumSize().Y;
    var chromeHeight = Mathf.Max(0f, currentPanelMinimum - currentBodyMinimum);
    var maximumBodyHeight = Mathf.Max(0f, maximumPanelHeight - chromeHeight);
    var contentHeight = BodyHost.GetCombinedMinimumSize().Y;
    var bodyHeight = Mathf.Min(contentHeight, maximumBodyHeight);

    _bodyScroll.CustomMinimumSize = new Vector2(
        _bodyScroll.CustomMinimumSize.X,
        bodyHeight);
    _bodyScroll.FollowFocus = true;
}
```

`Control.CustomMaximumSize` is forbidden because it is not a Godot 4.6 API.

This code is the first supported implementation to test, not a reason to ignore the red/green evidence. private void OnSlotPressed(int slot)
```csharp
{
    var info = _slotInfos[slot];
    if (!CanActivateSlot(slot, info))
        return;

    if (Mode == SaveLoadMode.Save && info.State == SaveSlotState.Valid)
    {
        EmitSignal(SignalName.OverwriteRequested, slot);
        return;
    }

    if (!TryBeginTerminal())
        return;

    DisableAllActions();
    EmitSignal(

            ? SignalName.SaveSlotSelected
            : SignalName.LoadSlotSelected,
        slot);
}
```

```csharp
public partial class SaveOverwriteConfirmationController : Control
{
    [Signal] public delegate void OverwriteConfirmedEventHandler(int slot);
    [Signal] public delegate void CancelRequestedEventHandler();

    public int Slot { get; set; }
    public Control InitialFocusTarget => _cancel;

    private Label _message = null!;
    private Button _overwrite = null!;
    private Button _cancel = null!;
    private bool _terminalEmitted;

    public override void _Ready()
    {
        _message = GetNode<Label>("%Message");
        _overwrite = GetNode<Button>("%OverwriteButton");
        _cancel = GetNode<Button>("%CancelButton");
        _message.Text = $"Slot {Slot + 1} already contains save data. Overwrite it?";
        _overwrite.Pressed += OnOverwrite;
        _cancel.Pressed += OnCancel;
    }

    private void OnOverwrite()
    {
        if (_terminalEmitted) return;
        _terminalEmitted = true;
        EmitSignal(SignalName.OverwriteConfirmed, Slot);
    }

    private void OnCancel()
    {
        if (_terminalEmitted) return;
        _terminalEmitted = true;
        EmitSignal(SignalName.CancelRequested);
    }
}
```
