# Battle preparation quality reference

- [Editable vector reference](battle-preparation-reference.svg)
- [Rendered review image](battle-preparation-reference.png)

This 1280×720 reference establishes the Constellation Grimoire quality bar using the retained battle background and existing character, enemy, and item artwork.

It deliberately demonstrates:

- Gold selected state on Health Potion
- Cyan keyboard/gamepad focus on Strength Tonic
- Normal state on Smoke Bomb
- Disabled state with reason on Warding Charm
- Gold primary **Begin Battle** action
- Player and enemy identity plates
- HP, MP, active-skill, first-turn, target, and effect hierarchy
- Input hints and rollback-supporting preparation copy
- Restrained constellation and partial-sigil ornament

The composition is a design artifact, not a Godot implementation scene.
