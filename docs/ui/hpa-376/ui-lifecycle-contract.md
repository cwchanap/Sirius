## Contract policy

Each row records:

1. observed `file:member` evidence;
2. required migration behavior;
3. one disposition: `Preserve`, `Fix in HPA-376`, or `Replace in HPA-378/379`;
4. protecting test evidence or downstream owner.

Unknown or absent focus, cursor, and restoration behavior is stated explicitly rather than inferred from Godot defaults. “HUD retained” means the current gameplay HUD is not explicitly hidden by the cited owner; it does not imply a shared HUD policy.

Configured Cancel has two runtime action surfaces. Settings keeps `pause_menu` mirrored to the effective `ui_cancel` keyboard binding and preserves `ui_cancel` controller events. It then synchronizes those effective events into Godot's `ui_close_dialog` action, which is what `AcceptDialog` consumes. Synchronization removes only exact injected instances it still owns, preserves native `ui_close_dialog` bindings, and replaces stale configured events on every apply. Main-Menu Settings remains a direct `ui_cancel` controller; hosted Inventory terminal `ui_cancel` and `toggle_inventory` actions are dispatched by `UIScreenHost`; `AcceptDialog`-derived owners consume `ui_close_dialog`.

Injected-event ownership is based on the exact `InputEvent` instance currently
stored in `InputMap`, not event equivalence. If another owner reconstructs
`ui_close_dialog` with an equivalent native event, the missing injected
instance is treated as stale ownership and discarded without erasing the
replacement.
